# Курсовая работа: Парсинг вакансий hh.ru и работа с PostgreSQL

## 📌 Описание проекта

Программа получает данные о работодателях и их вакансиях (из JSON-файла), сохраняет их в базу данных PostgreSQL и предоставляет удобный интерфейс для анализа вакансий.

Реализовано:
- Получение данных о компаниях и вакансиях.
- Сохранение данных в PostgreSQL с использованием `psycopg2`.
- Класс `DBManager` для работы с БД (SQL-запросы с JOIN, AVG, LIKE).
- Консольный интерфейс для просмотра:
  - списка компаний и количества вакансий,
  - всех вакансий с зарплатами и ссылками,
  - средней зарплаты,
  - вакансий с зарплатой выше средней,
  - вакансий по ключевому слову.

## 🛠 Технологии

- Python 3.10+
- PostgreSQL
- psycopg2
- python-dotenv
